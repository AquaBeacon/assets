# AquaBeacon 紹介映像

日本語字幕のみ、無音、40秒、16:9。
前回制作したロゴの紺・アクアに、音響を示すアンバーを加える。
水上と水中を同時に見せるBlenderの3D模式図を共通の舞台とする。

| 秒 | 主題 | 画面の説明 |
| --- | --- | --- |
| 0–5 | 光と音で、水中の位置を測る | 水上の親機、水中の子機、藻場の全体像 |
| 5–10 | 水上の親機が、位置の基準 | 衛星から親機のGPSへ。水中ではGPSを直接使えない |
| 10–17 | 音で、距離を測る | 親機から子機へ進むアンバーの波。距離＝音速×到達時間。有線で送信時刻を共有 |
| 17–24 | 光で、方向を測る | 子機のライトから親機のカメラへ向かうアクアの光。カメラで方向を捉える |
| 24–30 | 距離と方向から、位置を求める | 両方の信号と親機のGPSを合わせ、子機の位置を推定 |
| 30–36 | 撮影した映像を、正しい位置へ | 子機の下向きカメラから海底へ。撮影データを位置に結びつけ、3Dマッピングへ |
| 36–40 | AquaBeacon | 光と音で、藻場のマッピングへ。浅い海を想定し、濁りによる光の見失いに注意 |

## 資料と表現の対応

参照資料：ユーザー指定の `AquaBeacon.pptx`、更新日2026-09-23。

- 水中の位置推定と藻場のマッピング：スライド1、10、11。
- 音は親機から子機へ、光は子機から親機へ、有線による時刻同期：スライド12。
- 親機GPSと相対位置から子機の位置を求める：スライド11、12。
- 観測画像に位置を対応付けるマッピング：スライド13、16。
- 浅海域、濁りの制約、後処理を想定：スライド17–19、22、23。

図は説明用の模式モデル。信号の速度、距離、機体サイズは実寸を示さない。
位置推定とマッピングの性能が実証済みであるとは表現しない。
親機が海底の形状を測る図にはせず、子機のカメラが海底を撮る図にする。
